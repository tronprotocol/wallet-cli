# wallet-cli witness

Register and operate a TRON super representative candidacy.

## Synopsis

```
wallet-cli witness COMMAND
```

## Subcommands

| Command | Page | Description |
|---|---|---|
| `witness create` | [create.md](create.md) | Register the account as an SR candidate |
| `witness update` | [update.md](update.md) | Update the candidate information URL |
| `witness set-brokerage` | [set-brokerage.md](set-brokerage.md) | Set the SR-retained reward percentage |
